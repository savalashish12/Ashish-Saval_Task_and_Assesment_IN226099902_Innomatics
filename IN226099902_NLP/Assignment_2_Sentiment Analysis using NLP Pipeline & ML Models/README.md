# Assignment 2: Sentiment Analysis using NLP Pipeline

## Objective
Build an end-to-end NLP pipeline for sentiment classification using ML models.

## Steps Performed
- Data Loading and Understanding
- Text Preprocessing (Cleaning, Tokenization, Lemmatization)
- Feature Engineering (BoW, TF-IDF)
- Model Training (Logistic Regression, Naive Bayes, Decision Tree)
- Model Evaluation (Accuracy, Precision, Recall, F1 Score)

## Results
Logistic Regression performed best among all models.
