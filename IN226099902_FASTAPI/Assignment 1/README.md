## How to Run

1. Create virtual environment  
   python -m venv api  

2. Activate it  
   api\Scripts\activate  

3. Install packages  
   pip install fastapi uvicorn  

4. Run server  
   uvicorn main:app --reload  

5. Open in browser  
   http://127.0.0.1:8000/docs
